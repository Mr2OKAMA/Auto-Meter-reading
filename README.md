# Auto-Meter-reading

スマートフォンのブラウザから入力できる、日常点検用の軽量Webフォームです。

## サイト

- [日常点検フォームを開く](https://mr2okama.github.io/Auto-Meter-reading/daily_inspection_form.html)
- [リポジトリ](https://github.com/Mr2OKAMA/Auto-Meter-reading)

> GitHub Pagesで公開する場合は、リポジトリの **Settings → Pages** で公開設定を行ってください。公開後のサイトURLは通常、`https://mr2okama.github.io/Auto-Meter-reading/daily_inspection_form.html` です。

## 使い方

### 1. フォームを開く

`daily_inspection_form.html` をスマートフォンのブラウザで開きます。

### 2. 前回データを読み込む

画面上部の **「JSONファイルを選択またはドラッグ&ドロップ」** をタップし、前回保存した `inspection_summary_*.json` を選択します。

読み込みに成功すると、各施設・各項目の下に前回値が表示されます。

### 3. 点検日と点検時間を確認する

- **点検日**：現在の日付が自動入力されます。必要に応じて変更してください。
- **点検時間**：流量計施設は各施設ごとに入力します。入力欄をタップすると **「現在時間を入力」** ボタンが表示されます。

### 4. メーター値を入力する

以下の設備群に対応しています。

- **流量計施設**
  - 緑苑：電力量、流量（×10m3）
  - 深田酒倉：電力量、流量（深田）（×10m3）、流量（酒倉）（×10m3）
  - 川辺、八百津、和知、中恵土、川島第二、米野、東部第二、下羽栗、梅松、東部第一、芥見：点検時間、電力量、流量
  - 川島第二の二（環境楽園）、岐南西：点検時間、流量
- **上水・燃料・放流口**
  - 兼山ポンプ場：上水メーター、小出槽 油量
  - 川島ポンプ場：上水メーター
  - 長森ポンプ場：上水メーター、地下燃料 移送カウンター値合計、小出槽、井水メーター
  - 岐南ポンプ場：上水メーター（親）、上水メーター（子）、地下燃料 移送カウンター値、小出槽、井水メーター
  - Ａ点（三井川放流口）、Ｂ点（中屋川放流口）、Ｃ点（中部排水放流口）、Ｄ点（中屋川排水放流口）、Ｅ点（徳田支線放流口）：電力量

前回値を確認しながら、今回の値を入力できます。流量計施設の必須項目に加えて、上水・燃料・放流口の追加項目は必要なものだけ入力できます。

### 5. JSONファイルとして保存する

**「JSONファイルとして保存」** ボタンをタップすると、入力した全施設のデータが1つのJSONファイルとしてダウンロードされます。

ファイル名は次の形式です。

```text
inspection_summary_YYYYMMDD.json
```

例：

```text
inspection_summary_20260925.json
```

次回の点検時にこのJSONファイルを読み込むことで、前回値と今回値を比較できます。

## JSON形式

保存されるJSONデータは次の形式です。

```json
{
  "点検日": "2026-09-25",
  "データ一覧": [
    {
      "施設キー": "ryokuen",
      "施設名": "緑苑",
      "区分": "流量計施設",
      "点検時間": "09:00",
      "測定値": {
        "電力量": 340.5,
        "流量": 1250.0
      }
    },
    {
      "施設キー": "ginan_pump",
      "施設名": "岐南ポンプ場",
      "区分": "上水・燃料・放流口",
      "測定値": {
        "上水メーター（親）": 120.0,
        "上水メーター（子）": 118.5,
        "地下燃料 移送カウンター値": 42.0,
        "小出槽": 250.0,
        "井水メーター": 88.0
      }
    }
  ]
}
```

### 旧JSONとの互換性

- 新しい保存形式では、各施設を **施設キー + 測定値オブジェクト** で保存します。
- 読み込み時は `施設キー` または `施設名` を使って対応する施設へ前回値を表示します。
- 旧バージョンの `処理場A / 処理場B / 処理場C` 用JSONは、現行フォームに対応する施設が存在しないため前回値表示の対象外です。
- `電力` という旧項目名の読み替えは、**現在の施設名または施設キーと一致するデータ** に対してだけ `電力量` として行われます。

## 注意事項

- 入力値やJSONファイルはブラウザ内で処理されます。
- 保存したJSONファイルは、次回の点検まで安全な場所に保管してください。
- GitHub Pagesで利用する場合は、Pagesの公開設定が必要です。
- Tailwind CSSをCDNから読み込むため、初回表示時などにインターネット接続が必要です。
